# Contributing

Start with a small reproducible example and the exact toolchain and host version. Include units, tolerances, input data, and expected output for geometry or numerical issues.

Keep changes focused. Run the commands in README.md, add a regression test for a corrected defect, and report host integration checks separately from library tests. Use generated fixtures where possible; do not commit proprietary SDKs, model weights, credentials, or build outputs.

Performance claims require a reproducible workload, release build, hardware description, warm-up policy, repeated measurements, and raw results. Passing a test does not establish a general correctness or safety guarantee.
